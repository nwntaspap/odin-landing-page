# Landing Page Project

This is a visually polished and structured landing page designed to showcase the beauty of exploration and nature. It was built as part of **The Odin Project** curriculum to practice HTML and CSS skills, with a focus on layout, structure, and styling.

## 🌍 Project Overview

The landing page includes:

- A responsive header with a logo and navigation bar
- A hero section featuring a compelling call-to-action and scenic imagery
- An info section with card-based layout showcasing landscapes
- A quote section to inspire exploration
- A call-to-action banner to encourage engagement
- A footer with personal credits and social media links

## 🛠 Technologies Used

- **HTML5**
- **CSS3**
- **Google Fonts**
- **Material Icons**
- **Font Awesome**
